### `> whoami`

I'm a **Data Analyst** moving into **AI**. I started out asking questions of data, and these days I'm just as interested in what models can do with it.

I care about the full path from raw data to something people actually use: cleaning it, finding the story in it, modelling it, and putting it in front of people in a form that helps them decide.

I work in an **AI-assisted** way. I pair with tools like **Claude Code** to prototype quickly, test ideas early, and spend my time on the problem instead of the boilerplate.

- 🔍 **Analysis:** SQL, Python and dashboards that answer real questions
- 🤖 **AI / ML:** LLM apps, running models locally, and classic ML
- ⚡ **Shipping:** going from an idea to a working prototype, fast
- 🎯 **Looking for:** AI / ML engineering or AI-focused data roles
